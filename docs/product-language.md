# Product Language

## Voice

Fluel's voice should be calm, plain, and lightly reflective.

Preferred qualities:

- Quiet.
- Familiar.
- Gentle.
- Concrete.
- Low-pressure.
- User-centered.

Avoid language that feels mechanical, gamified, judgmental, or productivity
oriented.

## Core Phrases

Preserve these product phrases or their close equivalents:

- Things and places you live with.
- Time together.
- Quietly keep time.
- The quiet overview.
- Quiet history.
- Read back.
- Still with you.
- Moved out of daily life.
- Begin with one entry.
- Reuse a familiar starting point.
- Keep the start as precisely as you know it.
- See the whole shape first.
- Keep the next action close.
- Open new entries with a head start.

## Entry Language

Use "entry" for the user's saved record.

Use "thing or place" for what the entry represents.

Avoid replacing the product vocabulary with implementation-like or inventory
language such as item model, asset, object record, database row, collection
item, or possession record.

The early prototype used target-like language, but the later product language
settled around entries, things, places, and time together.

## Start And Precision Language

Preserved labels:

- Start.
- Started.
- Start range.
- Known as.
- Precision.
- Day.
- Month.
- Year.
- Exact day.
- Known to the month.
- Known to the year.
- Approximate start.

Preferred explanatory language:

- If you only know the month or year, switch the precision first.
- You can refine it later.
- The start stays exactly as you know it.

## Time Language

Preserved labels:

- Time together.
- Elapsed in full.
- Total days.
- Total months.
- Longest together.
- Longest together right now.
- Upcoming milestones.
- Based on the earliest possible start date.

Use "time together" before more technical phrases like elapsed duration.

## Archive Language

Preserved labels and meanings:

- Archive.
- Archived.
- Restore.
- Delete Permanently.
- Nothing is archived yet.
- Archived entries stay separate from what the user still lives with every day.

Archive means separate from daily life. It should not imply failure, loss, or
trash.

## Timeline Language

Preserved labels:

- Timeline.
- Timeline summary.
- All activity.
- Added.
- Updated.
- Archived.
- Recent 6 months.
- Recent year.
- All time.
- Monthly trends.
- Upcoming from this timeline.
- Visible entries.
- Approximate milestones.

Use "read back" for timeline review. It matches the original quiet-history
intent better than audit, log, or event stream.

## Preset Language

Preserved labels:

- Presets.
- Starter presets.
- Quick presets.
- Built-in presets.
- Custom presets.
- Pinned presets.
- Recent presets.
- Default preset.
- Create preset.
- Edit preset.
- Pin preset.
- Unpin preset.
- Open new entries with a head start.
- Shape reusable starting points for new entries.

Preset language should emphasize familiar starts and reusable shapes, not
automation.

## Starter Examples

Preserved example titles:

- This home.
- Wallet.
- Bag.
- Shoes.
- Watch.
- Notebook.
- Plant.
- Furniture.

Preserved example tone:

- A home is where daily life gathers.
- A wallet is usually one of the first things that leaves with the user.
- A plant shares the same light.
- A notebook holds ordinary thoughts.
- Furniture can stay through different rooms.

These examples define the emotional range of Fluel: small, concrete, ordinary,
and personal.

## Words To Avoid Unless Product Direction Changes

Avoid these as primary product language:

- Inventory.
- Asset.
- Warranty.
- Streak.
- Habit.
- Task.
- Goal.
- Lifecycle.
- Database.
- Record schema.
- Object.
- Metric dashboard as the primary metaphor.
- Event log as the primary metaphor.

Some of these may appear technically in a rebuild, but they should not become
the product's user-facing language.
